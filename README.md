# Project Name

**Person Centered Plan**

# Project Setup Instructions

## Prerequisites

Ensure you have the following installed on your system:

- **Flutter**: `3.27.4` (Stable)
- **Dart**: `3.6.2`
- **DevTools**: `2.40.3`

## Project Setup Steps

### 1. Clone the Repository

```sh
 git clone https://github.com/Quokka-Labs-LLP/Person-Centered-App-Flutter.git
 cd <project_directory>
```

### 2. Set Up Environment Files

Ensure all necessary `.env` files are present inside the `env` folder.

- .env.dev
- .env.stg
- .env.prod

### 3. Install Dependencies

Run the following command to install all required dependencies:

```sh
flutter pub get
```

### 4. Generate Required Code

Ensure all auto-generated code is ready:

- **For i18n** - lib/core/i18n

### 5. Run the Project

To run the application, use the following command:

```sh
flutter run
```

---

Your project should now be set up and ready to use!
