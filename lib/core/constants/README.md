# Constants Folder

This folder contains core constants and utilities used throughout the app to maintain consistency and improve maintainability.

## Files and Their Purpose

- **`api_const.dart`**: Defines API-related constants such as base URLs and endpoint paths.
- **`app_const.dart`**: Contains general app-related constants like the app version, name, and other static values.
- **`color_const.dart`**: Defines color constants to ensure consistent theming across the application.
- **`enum.dart`**: Contains enumerations used throughout the app for better type safety and code readability.
- **`font_const.dart`**: Stores font-related constants, including font sizes and styles.
- **`image_const.dart`**: Holds image asset paths and related constants for easier access and management.

This folder helps in centralizing commonly used constants, reducing redundancy, and making future updates easier.
