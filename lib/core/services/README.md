# Services Folder

The `services/` folder contains essential service modules that manage core functionalities such as networking, initialization, and shared preferences.

## Folder Structure

- **`dio/`**: Contains configurations and utilities for handling API requests using Dio.
- **`initializer/`**: Handles app initialization tasks, including dependency injection and setup procedures.
- **`shared_pref/`**: Manages local storage using shared preferences for saving and retrieving user data.

## Notes

- This folder is structured to ensure modular and scalable service management.
- Each subfolder contains specific functionalities to maintain clean and organized code.
- Ensure proper setup and initialization before using services in the app.

This structure keeps the application's core service logic well-organized and easy to maintain.
